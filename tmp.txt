*** Gemini-Anfang
Nein, `onStart` ist **kein Objekt**, sondern eine **Funktion** (genauer gesagt eine sogenannte **Callback-Funktion**).

In JavaScript und TypeScript sind Funktionen sogenannte *First-Class Citizens*. Das bedeutet, dass man Funktionen genau wie Variablen, Zahlen oder Strings **als Parameter an andere Funktionen übergeben** kann.

Hier ist die genaue Erklärung, warum diese Syntax so aussieht und wie sie funktioniert:

### 1. Die Typdefinition in `UIRenderer.ts`

In der Methode `renderStartScreen` sagst du dem TypeScript-Compiler, welchen Typ der Parameter haben muss:

```typescript
renderStartScreen(onStart: (name: string, roomId: string, difficulty: string) => void)

```

Das bedeutet:

* `onStart` ist der Name des Parameters.
* `(name: string, roomId: string, difficulty: string) => void` beschreibt die **Signatur** der erwarteten Funktion: Sie nimmt drei Parameter entgegen (Name, Raum-ID, Schwierigkeitsgrad) und gibt nichts zurück (`void`).

### 2. Der Aufruf in `main.ts`

Wenn du `renderStartScreen` aufrufst, übergibst du dieser Methode ein Stück ausführbaren Code (eine anonyme Funktion bzw. einen Arrow-Function-Ausdruck), das genau dann aufgerufen werden soll, wenn der Benutzer im Startbildschirm auf den Absende-Button klickt:

```typescript
this.renderer.renderStartScreen((name, roomId, difficulty) => {
    // Dieser Code wird erst ausgeführt, wenn das Formular abgeschickt wird!
    console.log("Gestartet mit:", name, roomId, difficulty);
});

```

### 3. Warum macht man das so? (Trennung von Logik und UI)

Das ist das Kernstück der sauberen Architektur (**Trennung von UI und Spiel-Logik**):

* Der `UIRenderer` kümmert sich nur um das HTML, liest die Eingabefelder aus und kriegt von außen eine Funktion (`onStart`) reingereicht. Er muss **nicht wissen**, was danach passiert (z. B. ob ein Timer startet oder wie das Spiel initialisiert wird).
* Der `GameController` (in `main.ts`) bestimmt hingegen, *was* passieren soll, wenn der Start-Button gedrückt wird, hält sich aber komplett aus dem HTML-Code heraus.

```typescript
import { UIRenderer } from './ui/UIRenderer.js';

class GameController {
  private renderer;
  private roomsData: any = null;

  // Neuer Spielzustand
  private currentRoom: any = null;
  private currentDifficulty: string = 'easy';
  private currentPuzzleIndex: number = 0;

  constructor() {
    this.renderer = new UIRenderer('app');
  }

  public async init() {
    try {
      const response = await fetch('./src/data/rooms.json');
      if (!response.ok) throw new Error("Konnte rooms.json nicht laden");

      const data = await response.json();
      this.roomsData = data.rooms;

      const roomSummaries = this.roomsData.map((room: any) => ({
        id: room.id,
        name: room.name
      }));

      this.renderer.renderStartScreen(roomSummaries, (name, roomId, difficulty) => {
        this.startGame(name, roomId, difficulty);
      });

    } catch (error) {
      console.error("Fehler:", error);
      alert("Fehler beim Laden von rooms.json. Läuft dein Live Server?");
    }
  }

  private startGame(name: string, roomId: string, difficulty: string) {
    console.log(`Spieler: ${name} gestartet im Raum: ${roomId} (${difficulty})`);

    // Raum und Schwierigkeitsgrad abspeichern
    this.currentRoom = this.roomsData.find((r: any) => r.id === roomId);
    this.currentDifficulty = difficulty;
    this.currentPuzzleIndex = 0; // Wir fangen beim 1. Rätsel (Index 0) an

    // Das erste Rätsel laden
    this.loadCurrentPuzzle();
  }

  private loadCurrentPuzzle() {
    // Die Rätsel-Liste für den gewählten Schwierigkeitsgrad holen
    const puzzles = this.currentRoom.difficulties[this.currentDifficulty];

    // Prüfen, ob wir alle Rätsel gelöst haben
    if (this.currentPuzzleIndex >= puzzles.length) {
      alert("🎉 Wow! Du hast alle Rätsel in diesem Raum gelöst!");
      this.init(); // Zurück zum Startbildschirm
      return;
    }

    const currentPuzzle = puzzles[this.currentPuzzleIndex];

    // An den Renderer übergeben
    this.renderer.renderPuzzle(
      currentPuzzle,
      (answer) => this.checkAnswer(answer, currentPuzzle),
      () => { console.log("Hinweis wurde angefordert"); }
    );
  }

  private checkAnswer(userAnswer: string, puzzle: any) {
    // Antwort prüfen (Groß-/Kleinschreibung ignorieren, Leerzeichen entfernen)
    const isCorrect = userAnswer.trim().toUpperCase() === puzzle.solution.toUpperCase();

    if (isCorrect) {
      alert("✅ Richtig! Super gemacht!");
      this.currentPuzzleIndex++; // Zum nächsten Rätsel springen
      this.loadCurrentPuzzle();
    } else {
      alert("❌ Leider falsch. Probier es noch einmal!");
    }
  }
}

// Spiel starten

gameController.init();
```

### 🧠 3. Die erweiterte Spiellogik in `src/main.ts`

Hier integrieren wir den `Player`, den `setInterval`-Timer (der jede Sekunde herunterzählt) und die Logik zum Kaufen von Zeit oder Abziehen von Punkten bei Fehlern/Hinweisen.

```typescript
import { UIRenderer } from './ui/UIRenderer.js';
import { Player } from './models/Player.js';

class GameController {
  private renderer;
  private roomsData: any = null;

  private player!: Player;
  private currentRoom: any = null;
  private currentDifficulty: string = 'easy';
  private currentPuzzleIndex: number = 0;

  private timeLeft: number = 90; // 90 Sekunden Startzeit pro Raum
  private timerInterval: any = null;

  constructor() {
    this.renderer = new UIRenderer('app');
  }

  public async init() {
    try {
      const response = await fetch('./src/data/rooms.json');
      if (!response.ok) throw new Error("Konnte rooms.json nicht laden");

      const data = await response.json();
      this.roomsData = data.rooms;

      const roomSummaries = this.roomsData.map((room: any) => ({
        id: room.id,
        name: room.name
      }));

      this.renderer.renderStartScreen(roomSummaries, (name, roomId, difficulty) => {
        this.startGame(name, roomId, difficulty);
      });

    } catch (error) {
      console.error("Fehler:", error);
      alert("Fehler beim Laden von rooms.json. Läuft dein Live Server?");
    }
  }

  private startGame(name: string, roomId: string, difficulty: string) {
    // Spieler mit Startpunkten (z.B. 500) erstellen
    this.player = new Player(name, 500);
    this.currentRoom = this.roomsData.find((r: any) => r.id === roomId);
    this.currentDifficulty = difficulty;
    this.currentPuzzleIndex = 0;
    this.timeLeft = 90;

    this.startTimer();
    this.loadCurrentPuzzle();
  }

  private startTimer() {
    if (this.timerInterval) clearInterval(this.timerInterval);

    this.timerInterval = setInterval(() => {
      this.timeLeft--;
      this.renderer.updateStatusDisplay(this.player.points, this.timeLeft);

      if (this.timeLeft <= 0) {
        this.timeLeft = 0;
        clearInterval(this.timerInterval);
        alert("⏰ Die Zeit ist abgelaufen! Das Abenteuer ist vorbei.");
        this.init(); // Zurück zum Start
      }
    }, 1000);
  }

  private loadCurrentPuzzle() {
    const puzzles = this.currentRoom.difficulties[this.currentDifficulty];

    if (this.currentPuzzleIndex >= puzzles.length) {
      clearInterval(this.timerInterval);
      this.renderer.renderVictory(this.player.points, () => this.init());
      return;
    }

    const currentPuzzle = puzzles[this.currentPuzzleIndex];

    this.renderer.renderPuzzle(
      currentPuzzle,
      this.player.points,
      this.timeLeft,
      (answer) => this.checkAnswer(answer, currentPuzzle),
      // Callback für Hinweis (-50 Punkte)
      () => {
        this.player.removePoints(50);
        this.renderer.updateStatusDisplay(this.player.points, this.timeLeft);
      },
      // Callback für Zeit kaufen (-100 Punkte für +30 Sekunden)
      () => {
        if (this.player.points >= 100) {
          this.player.removePoints(100);
          this.timeLeft += 30;
          this.renderer.updateStatusDisplay(this.player.points, this.timeLeft);
          alert("⏱️ Super! Du hast dir 30 Sekunden Extra-Zeit gekauft.");
        } else {
          alert("❌ Du hast nicht genug Punkte, um Zeit zu kaufen! (Benötigt: 100 Pkt)");
        }
      }
    );
  }

  private checkAnswer(userAnswer: any, puzzle: any) {
    let isCorrect = false;

    // Array-Vergleich (z.B. bei Card-Grids) oder String-Vergleich
    if (Array.isArray(puzzle.solution)) {
      isCorrect = Array.isArray(userAnswer) &&
                  userAnswer.length === puzzle.solution.length &&
                  userAnswer.every((val, index) => val === puzzle.solution[index]);
    } else if (typeof puzzle.solution === 'string') {
      const cleanUserAnswer = String(userAnswer).trim().toUpperCase();
      const cleanSolution = puzzle.solution.trim().toUpperCase();
      isCorrect = cleanUserAnswer === cleanSolution;
    }

    if (isCorrect) {
      alert("✅ Richtig! +100 Punkte!");
      this.player.addPoints(100); // Belohnung für richtige Antwort
      this.currentPuzzleIndex++;
      this.loadCurrentPuzzle();
    } else {
      alert("❌ Leider falsch! -20 Punkte.");
      this.player.removePoints(20); // Strafe für falsche Antwort
      this.renderer.updateStatusDisplay(this.player.points, this.timeLeft);
    }
  }
}

// Spiel starten
const gameController = new GameController();
gameController.init();
```

### 📂 1. Der neue Highscore-Manager (`src/logic/HighscoreManager.ts`)

Erstelle eine neue Datei `src/logic/HighscoreManager.ts`. Sie verwaltet das Laden und Speichern der Bestenliste (sortiert nach Punkten, maximal die Top 5):

```typescript
export interface HighscoreEntry {
  name: string;
  points: number;
  roomName: string;
  date: string;
}

export class HighscoreManager {
  private static STORAGE_KEY = 'escape_room_highscores';

  // Highscores laden
  static getHighscores(): HighscoreEntry[] {
    const data = localStorage.getItem(this.STORAGE_KEY);
    if (!data) return [];
    try {
      return JSON.parse(data);
    } catch {
      return [];
    }
  }

  // Neuen Score hinzufügen und speichern
  static addScore(name: string, points: number, roomName: string): HighscoreEntry[] {
    const scores = this.getHighscores();

    const newEntry: HighscoreEntry = {
      name,
      points,
      roomName,
      date: new Date().toLocaleDateString('de-DE')
    };

    scores.push(newEntry);

    // Absteigend nach Punkten sortieren (höchste Punkte zuerst)
    scores.sort((a, b) => b.points - a.points);

    // Nur die besten 5 behalten
    const topScores = scores.slice(0, 5);

    localStorage.setItem(this.STORAGE_KEY, JSON.stringify(topScores));
    return topScores;
  }
}
```
